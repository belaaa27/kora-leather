# Kora Leather

**Crafted for Everyday Elegance.**

Kora Leather is a modern leather goods storefront concept designed for the Ethiopian market. The project explores a premium digital shopping experience through elegant typography, a warm color palette, and a clean, modern interface.

> **Project Status:** In Development

## Overview

Kora Leather is Project 01 of my 30-Website Challenge, an initiative to build and document 30 web projects while strengthening my frontend development and UI implementation skills.

The concept focuses on presenting leather goods through a refined visual identity that communicates quality, simplicity, and timeless elegance.

## Design Direction

The visual identity is built around warm, natural colors and elegant typography.

### Brand Colors

| Color | Hex Code | Purpose |
|---|---|---|
| Espresso | `#35251F` | Primary brand color |
| Cognac | `#A66A43` | Accent color |
| Ivory | `#F8F4ED` | Background color |
| White | `#FFFFFF` | Clean surfaces |
| Main Text | `#29211D` | Primary text |

### Typography

- **Playfair Display** — Headings and editorial elements.
- **Inter** — Body text and interface elements.

## Getting Started

To run the project locally:

### 1. Clone the repository

```bash
git clone https://github.com/belaaa27/kora-leather.git
```

### 2. Navigate to the project directory

```bash
cd kora-leather
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

### 5. Build for production

```bash
npm run build
```
